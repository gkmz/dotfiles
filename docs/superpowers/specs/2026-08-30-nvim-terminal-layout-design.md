# Neovim 终端布局稳定性设计

## 目标

让右侧终端始终作为独立的整列主终端存在；底部临时终端及其后续左右分屏只发生在左侧编辑区内部，不改变右侧主终端的高度。

## 布局模型

顶层窗口树固定为“左侧编辑区 + 右侧主终端”。左侧编辑区内部再组织编辑器窗口和底部临时终端组：

```text
顶层：左侧编辑区 | 右侧主终端
左侧分支：编辑器窗口 / 底部临时终端组
```

终端模块维护左侧编辑窗口引用。打开底部终端时，无论当前焦点在哪个窗口，都先定位到左侧编辑分支再执行 split。打开右侧主终端后设置窗口高度固定约束，避免其他分支 split 触发重新均衡。

## 行为

- 右侧主终端使用垂直 split，占据右侧整列。
- 底部临时终端只从左侧编辑窗口向下 split。
- 底部临时终端可继续左右 split，新增窗口仍属于左侧分支。
- 从右侧终端打开底部终端不会改变右侧终端高度。
- 隐藏或关闭底部终端后，右侧主终端仍保持整列高度。

## 影响范围

- `nvim/lua/utils/terminal.lua`：记录编辑区锚点、将 bottom split 限定在左侧分支、固定右侧终端高度。
- `nvim/tests/terminal_layout.lua`：headless 验证窗口树和右侧终端高度稳定。

不改变终端命令、编号语义、Codex/Claude 相关入口和普通编辑器窗口快捷键。
